# NPE convergence

Code and paper-support artifacts for "The Statistical Accuracy of Simulation-Based Posterior Estimation Methods".

Large local result directories are intentionally ignored by git. The public repository is for code, notebooks, and lightweight project files; durable result archives are handled separately.

## Repository layout

- `npe_convergence/`: package code and experiment launch scripts.
- `scripts/`: aggregation, audit, plotting, and postprocessing scripts.
- `notebooks/`: analysis and plotting notebooks.
- `tests/`: test suite where available.

The repo-root `paper.tex` is managed on Overleaf and is ignored locally.
